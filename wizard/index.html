Trinity Panel

Setup wizard

This installs Trinity Panel onto your own Cloudflare account. Four steps, no terminal commands, nothing stored on any machine but yours. Your API token is used once, in this browser session, and is never written to disk.

1 Sign up and verify a Cloudflare account

Trinity Panel runs on Cloudflare Workers. The free plan is enough for personal use. If you already have an account, skip to step 2.

  1. Create the account at dash.cloudflare.com/sign-up using an email you can read right now.
  2. Verify the email. Cloudflare sends a confirmation link. An unverified account cannot create Workers, and the failure it produces later is not obvious, so do this first.
  3. Register a workers.dev subdomain — open Workers & Pages in the dashboard and accept the subdomain it offers. Your panel will live at <name>.<subdomain>.workers.dev.
No domain name and no payment method are required. A custom domain is optional and can be attached later.

2 Create an API token

The button below opens Cloudflare's token page with the permissions pre-selected. Review them, scroll to the bottom, then Continue to summary → Create Token. Copy the token once — Cloudflare will not show it again.

PermissionWhy it is needed
Workers Scripts · EditUpload the Worker itself.
Workers KV Storage · EditCreate the namespace that stores your settings.
Account Settings · ReadDiscover your account ID and workers.dev subdomain.
Workers Routes / DNS · EditOnly used if you attach a custom domain. Harmless otherwise.
Scope it down if you prefer. Only the first three rows are required by this installer. The pre-selected link includes the optional two so a custom domain works later without making a second token. You can deselect them.

On the token page, set Account Resources to the account you want Trinity Panel installed on, and leave the token untouched otherwise.

3 Paste the token and install

Held in this page only. Sent to the local installer on this machine, used against Cloudflare's API, and discarded when you close the tab.

Compiles the Worker and uploads it over Cloudflare's API. Creates one Worker, one KV namespace and one Durable Object on your account. Nothing else is touched.

Becomes part of your hostname. Pick something unremarkable — obviously proxy-shaped names attract attention. Leave blank for a random one.

Must be a hostname on a zone already in this Cloudflare account.
